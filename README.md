把 qPCR 下机 Excel 一键变成能直接粘进 GraphPad Prism 的相对表达量表格。

导入下机文件后软件会自动认出里面有哪些目标基因和样本，把样本聚成实验分组；你只需要在界面上勾选内参基因、指定对照组，点一下计算，就能拿到按 2^-ΔΔCt 归一化的结果，复制或导出后直接进 Prism 画图。

面向的是每次跑完 qPCR 都要手动在 Excel 里排 ΔΔCt 的实验人员：省掉重复劳动，同时把容易出错的地方（内参配对、坏孔剔除、复孔一致性）显式暴露出来供核对。

## 快速开始

到 [Releases](https://github.com/JiangWY666/qpcr-analysis-tool/releases) 下载 `qPCR_Analyzer.zip`，解压后双击文件夹里的 `qPCR_Analyzer.exe` 即可，不需要装 Python。整个文件夹要一起保留，不要只拷走 exe。

想先试试的话，仓库里的 `examples/demo_qPCR_data.xlsx` 是一份可以直接导入的演示数据（数值为虚构，但结构与真实的 Bio-Rad CFX 导出完全一致）。

1. **选择文件**：点「选择文件…」或把 Excel 直接拖进窗口
2. **确认识别结果**：左侧会列出所有基因和自动聚好的分组，右侧「孔位数据」页签能看到每个孔的 Cq
3. **勾选内参基因**：常见管家基因（GAPDH、ACTB、18S 等）会自动预勾选，可以改；选多个内参时按几何平均处理
4. **核对配对预览**：切到「配对预览」页签，确认软件把哪几个孔认成了同一个生物学重复（详见下文「生物学重复配对」）
5. **指定对照组**：单击分组行进行选择，双击该行设置为对照组，其余组都相对它归一化
6. **点「开始计算」**，在「分析结果」页签查看宽表
7. **导出**：点「复制到剪贴板」直接 Ctrl+V 进 Prism，或者「导出 Excel…」存成文件

窗口顶部只有在出现需要人工确认的问题（配对方向有歧义、某个生物学重复因缺内参整体出局等）时才会弹出一条黄色警告条，平时不占地方。

## 计算口径

对每个样本 `s`、每个目标基因的第 `i` 个孔：

```
ref_mean(s) = 内参基因在该样本内所有复孔 Cq 的算术平均
              （选了多个内参时先各自求均值再平均，等价于表达量的几何平均）
ΔCt_i       = Cq_i − ref_mean(s)
ΔΔCt_i      = ΔCt_i − mean(对照组该基因所有孔的 ΔCt)
RQ_i        = 2^(−ΔΔCt_i)
```

几个要点：

- **目标基因逐孔计算，不预先平均**，所以每组会输出 n 个值，在 Prism 里能直接画 mean ± SD 并做统计检验
- **内参在样本内先平均**再作为基线。样本已经命名成 `LPS-1 / LPS-2 / LPS-3` 时，每个生物学重复自然用自己的内参校正；同一个样本名下藏着多个生物学重复时，靠下面的「生物学重复配对」达到同样效果
- 对照组自身的 RQ 均值≈1（因为是先对 ΔCt 取算术平均再取 2 的幂，所以是接近 1 而非精确等于 1，这是标准做法）

「样本」和「分组」是两层概念：内参归一化永远在**样本**这一层做，聚类出来的**分组**只决定导出宽表的列以及谁是对照。下机表里复孔同名时，两层是重合的。

## 生物学重复配对

很多下机表里，同一个样本名下的 3 个孔其实是 3 只不同的动物，而不是同一管 cDNA 分出来的技术复孔。这时候如果先把 3 个内参孔平均掉再去减目标基因，个体之间的上样量差异就被重新混了回去——1 号动物的 IL6 会被 2 号、3 号动物的 GAPDH 一起校正。

左侧「生物学重复」里的复选框**默认勾选**，处理办法是把 `CT` 临时拆成 `CT-1 / CT-2 / CT-3`：每个生物学重复下每个基因只剩一个孔，内参与目标基因天然 1:1 配对，每个生物学重复都只用自己的 GAPDH 做基线。分组、宽表的列、导出仍然按原始样本名 `CT` 进行，拆分只发生在归一化这一层。

**什么时候该关掉**：一管 cDNA 分成 2~3 孔上样的技术复孔。这种情况下同一样本的几个孔本来就是同一份模板，取平均反而更稳。取消勾选后回到「内参在样本内先平均」的老口径。

判断方法：看上样记录，同一个样本名下的孔是来自不同生物学重复（生物学重复，勾选）还是同一份 cDNA（技术复孔，取消勾选）。两种口径的均值差别通常不大，但标准差会明显不同——生物学重复配对不会把个体差异平均掉，SD 更接近真实的组内变异。

### 配对预览

「配对预览」页签是核对配对是否正确的唯一手段，每个原始样本一个小节，行是生物学重复（一个生物学重复），列是各基因，格子里是这个生物学重复在该基因上用的孔：

```
CT · 横向排列
重复 1    A01    A04    E01    E04
重复 2    A02    A05    E02    E05
重复 3    A03    A06    E03    E06
```

同一行的孔必须真的来自同一个生物学重复。对不上就改「孔位排列方向」，或者关掉生物学重复配对。方向有歧义或不一致的样本会被高亮，下方也会写明原因。

### 孔位排列方向

决定同一个基因的多个孔按什么顺序编号成 1、2、3 号重复：

- **自动识别**（默认）：同一行的孔按列号从左到右排，同一列的孔按行号从上到下排。一维排列的板子（绝大多数情况）都能准确判断
- **横向优先**：先横着走完一行再换下一行
- **纵向优先**：先竖着走完一列再换下一列

重复数较多、孔排成方块（既跨行又跨列）时，自动识别没法判断到底是横着上样还是竖着上样，会退回先横后竖并给出警告；这时按实际上样方式手动指定一次即可，指定后不再提示。

### 拆分带来的两个副作用

- **某个内参孔失效会带走整个生物学重复**。不拆分时坏掉一个内参孔只是被平均掉，几乎无感；拆分后这个生物学重复没有内参基线可用，它的所有基因都会退出计算。软件会在顶部警告条里写明是「哪个样本的第几号重复」以及一共少了几个孔，不会静默丢数据
- **某个样本各基因孔数对不上时不拆它**。比如 GAPDH 有 3 孔而 IL6 只有 2 孔，无法一一配对，该样本会退回按内参均值归一化，并单独给出提示

拆分开启时，分组按原始样本名进行，`CT-1 / CT-2 / CT-3` 会自动回到 `CT` 组。

「合并样本名末尾的编号」与拆分是两件互不干扰的事，两者可以同时打开：拆分处理**同名多孔**，合并处理**不同名但属于同一实验组**的样本。下机表里两种命名常常混在一块板上——如果你的生物学重复在上机时就分别命名成了 `PBS1 / PBS2`、`G43-L1 / G43-L2`，勾上这个选项就会把它们并成 `PBS`、`G43-L` 两组，组内依旧保留各自的配对关系。

## 未检出孔（NA / 空 Cq）

下机表中如果某行仍有 `Well`、`Target` 和 `Sample`，但 `Cq` 为空、为 `NA` 或 `Undetermined`，软件会保留这条孔记录及其孔位配对关系，不会把它当成空行。

界面默认将未检出孔按 protocol 的最大循环数参与分析，最大循环数默认是 `40`，可以编辑。也可以切换为「剔除，不参与统计」。切换策略不会改变 Target、Sample、Well 或生物学重复编号；导出的 `明细QC` 会记录最终策略，并标记该孔是按最大循环数补入还是被剔除。
## 导出内容

导出的 Excel 有两个工作表。

**`Prism`** —— 宽表，纯数值区，方便整块框选复制：

| | IL1b | | | | IL6 | | | |
|---|---|---|---|---|---|---|---|---|
| | CT | PBS | LPS | LPS+药 | CT | PBS | LPS | LPS+药 |
| | 1.02 | 1.31 | 2.45 | 2.51 | 0.98 | 1.22 | 2.10 | 2.33 |
| | 0.97 | 1.28 | 2.38 | 2.44 | 1.03 | 1.19 | 2.05 | 2.29 |

第 1 行是基因名（跨列合并），第 2 行是组名，第 3 行起每行一个复孔的值。列的顺序由界面上的分组顺序决定，用「上移 / 下移」调成你想要的出图顺序。

**`明细QC`** —— 溯源与质控，包含逐孔的完整计算链路（Cq、内参均值、ΔCt、ΔΔCt、RQ）、每个分组的 n / 均值 / 标准差、复孔一致性检查，以及本次分析用的参数。被剔除的孔和无效孔也会列在里面并注明原因，不会静默丢数据。

逐孔明细的最后两列是「原样本名」和「重复编号」，即使界面上只看得到 `CT-2`，也能一眼对回下机表里的 `CT`。分析参数里会记录这次用的复孔处理模式、孔位排列方向和拆分了哪些样本，拆分过程中的提示也一并写进去，报告脱离软件也能复现。

## 支持的文件格式

不写死列的位置，而是扫描表格找同时含有 `Target`、`Sample`、`Cq`（或 `Ct` / `Cp`）三列的表头行，所以下面这些都能直接读：

- Bio-Rad CFX Maestro / CFX Manager 导出的 `Quantification Cq Results`
- ABI QuantStudio、7500 系列导出的 Results 表
- 自己整理的表格，只要有这三列即可

Cq 为空、`N/A`、`Undetermined` 或非正数的孔会被判为无效，默认不参与计算，并在界面里灰显标注。

## 质控功能

- 同一样本同一基因的复孔 Cq 标准差超过 0.5 时，计算后会在孔位表里标黄提示，可以取消勾选坏孔后重新计算。这项检查始终按**原始样本名**分桶，开不开生物学重复配对都是同一批数字
- 某个样本缺内参数据时会整体跳过并给出明确警告，不会算出错误结果
- 每个孔都有「参与计算」复选框，随时手动剔除离群孔
- 需要人工确认的问题会汇总到窗口顶部的警告条，不用翻到结果页底部才发现

## 从源码运行与打包

```powershell
# 首次准备
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 直接运行
.\.venv\Scripts\python.exe main.py

# 跑测试
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

# 打包成文件夹，产物在 dist\qPCR_Analyzer\，发布包为 dist\qPCR_Analyzer.zip
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

打包脚本默认排除 QtWebEngine、Qt3D 等用不到的 Qt 模块来控制体积。默认是文件夹（onedir）形式，启动时不必每次解压；加 `-OneFile` 可以打成单文件，拷贝方便但冷启动更慢。

## 环境要求

Windows 10 / 11，Python 3.10 以上（开发环境为 3.14）。依赖只有 PySide6 和 openpyxl，计算部分是纯标准库实现，没有 pandas / numpy。

## 关于测试数据

仓库里**不包含任何真实实验数据**，`.gitignore` 默认屏蔽所有 `.xlsx / .xls / .csv`，只白名单放行 `examples/demo_qPCR_data.xlsx`，所以把下机文件放进项目目录也不会被误提交。

测试分两类：一类只依赖仓库自带的演示数据，任何人 clone 下来都能跑；另一类针对开发者本机的真实下机文件做精确数值断言，文件不存在时会自动跳过。所以你看到若干 skip 是正常的。
